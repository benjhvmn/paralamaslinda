# Cositas de ti que me hacen feliz

Página interactiva estática para GitHub Pages. La página y las imágenes están dentro de `index.html`.

## Publicarla con GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube `index.html` y `README.md` a la raíz del repositorio.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`, luego guarda.
6. GitHub mostrará el enlace de la página en esa misma sección cuando termine de publicarla.
